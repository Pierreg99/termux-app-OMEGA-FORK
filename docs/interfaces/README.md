# OMEGA Interface Gallery

Repository reference visuals for the OMEGA P1 Terminal UX track.

| Interface | Purpose |
|---|---|
| `omega-terminal-session-drawer.svg` | Session drawer, active/background states and primary actions |
| `omega-terminal-toolbar.svg` | Toolbar surface, extra-key actions and keyboard/inset behavior |
| `omega-extra-keys.svg` | Extra-key grid and interaction-state model |

These are design-reference pictures, not captures of a running Android build. Device PNG screenshots belong to the QA evidence set after emulator/device validation.
