# OMEGA Changelog

## Unreleased — P1 Terminal UX

### Added
- OMEGA Terminal UX P1 specification.
- Interface reference mockups for session drawer, toolbar and extra-keys surfaces.
- P1 test matrix and manual QA checklist.
- Roadmap tracking for session switching, extra keys and modern insets.

### Changed
- Terminal drawer/action surfaces now use the OMEGA spacing and touch-target tokens.
- Terminal toolbar uses an OMEGA semantic surface token instead of a hard-coded black background.
- Dialog/button styling uses OMEGA semantic accent colors while preserving the existing Termux component hierarchy.

### Compatibility
- Terminal engine and session services remain unchanged.
- Existing plugin integration points remain unchanged.

## Previous — P0 Design System v1

- Added OMEGA semantic color tokens.
- Added OMEGA spacing, shape and touch-target tokens.
- Established dark-first OMEGA theme resources.
